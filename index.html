Backend Database: Firebase Cloud Firestore

Hubungkan ke Firebase agar aplikasi tersinkronisasi real-time antar perangkat (HP & Laptop) dan siap di-hosting di GitHub Pages.

Belum Terhubung

Konfigurasi disimpan aman di browser Anda dan langsung mengaktifkan sinkronisasi cloud real-time.

Koneksi Google Sheets via Google Apps Script

Hubungkan web app ini langsung ke spreadsheet Anda (seperti file spreadsheet Catatan Keuangan) agar setiap data transaksi beserta sumber dompetnya otomatis masuk ke baris tabel.

URL ini disimpan secara aman di browser lokal Anda.

3 Langkah Mudah Menyiapkan Skrip:

1
Buka Spreadsheet & Apps Script: Buka Google Sheet Anda → Klik menu Ekstensi (Extensions) → Pilih Apps Script.
2
Salin Kode Skrip Berikut:

Ganti semua isi di editor Code.gs dengan kode ini:

function doPost(e) {
  try {
    var sheetName = "Catatan_Transaksi";
    var ss = SpreadsheetApp.getActiveSpreadsheet() || SpreadsheetApp.openById("1SJxMRkw8qQb13gMa8XD0jcPYeJKpNUftsvLLodfZdQQ");
    var sheet = ss.getSheetByName(sheetName);
    
    // Jika sheet belum ada, otomatis buatkan beserta header-nya
    if (!sheet) {
      sheet = ss.insertSheet(sheetName);
      sheet.appendRow([
        "ID", "Timestamp", "Tanggal", "Jenis", 
        "Kategori", "Subkategori", "Nominal", 
        "Dompet_Sumber", "Catatan"
      ]);
      sheet.getRange(1, 1, 1, 9).setFontWeight("bold").setBackground("#10b981").setFontColor("#ffffff");
    }
    
    var data = JSON.parse(e.postData.contents);
    var rows = Array.isArray(data) ? data : [data];
    
    rows.forEach(function(item) {
      sheet.appendRow([
        item.id || Utilities.getUuid(),
        item.timestamp || new Date(),
        item.date || "",
        item.type || "Pengeluaran",
        item.category || "",
        item.subcategory || "",
        Number(item.amount) || 0,
        item.wallet || "",
        item.note || ""
      ]);
    });
    
    return ContentService.createTextOutput(JSON.stringify({
      status: "success", 
      message: "Berhasil dicatat ke Google Sheets"
    })).setMimeType(ContentService.MimeType.JSON);
    
  } catch (err) {
    return ContentService.createTextOutput(JSON.stringify({
      status: "error", 
      message: err.toString()
    })).setMimeType(ContentService.MimeType.JSON);
  }
}
3
Terapkan (Deploy) Sebagai Web App: Klik tombol biru Deploy di kanan atas → Pilih New deployment → Pilih type Web app → Pada Who has access pilih Anyone (Siapa saja) → Salin Web App URL dan tempelkan ke kolom pengaturan di atas!
